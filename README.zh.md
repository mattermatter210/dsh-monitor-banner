# dsh-monitor-banner

> 在 DeepSeek Harness 界面底部常驻一行，告诉你那份 Markdown 监控日志已经几天没更新了。

## 为什么做这个

如果你有一份要按周或按月更新的清单——行情监控、持仓检查、健康记录、竞品跟踪——真正的问题往往不是「没有表」，而是**忘了看，也不知道它是不是过期了**。

这个插件把「新鲜度」放到你一定会看到的地方：窗口最底下那一条。绿点表示还在期内，橙点表示该跑一次了。

```text
● 监控日志: 今天 · 全部在期内                        [ ▾ 5 ]  ↻

点 [ ▾ 5 ] 就地展开，每个指标一个任务：
  ○ 四大厂 capex 指引 → 上调              每季度 · 1 天前 · 在期内
  ○ CDX HY/iTraxx → 否                    每周 · 今天 · 在期内
  ● 花旗 CESI-CECID → 仍在上行            每月 · 31 天前 · 到期
```

## 它怎么工作

- **Host 侧**把表格里的每个指标当作一个独立任务：按「每周/每月/每季度」各自折算到期阈值，算出每个任务距今天数，同时保留最新一行作为整体状态
- 通过 `GET /dsh-monitor-banner/status` 把结果交给界面
- **Client 侧**挂在 `shell.bottom` 槽。折叠时只占**一行 22px**：`监控日志: 今天 · 全部在期内`
- **任务多于一个时才出现 `▾ N`**：点开就地列出每个指标一个任务，各自标「节奏 · 几天前 · 到期/在期内」；只有一个任务时不显示展开按钮（那一行本身就是全部）
- 配了多份日志时，展开后按文件名分组，`📂` 出现在每个文件标题行上
- **点文字**用系统默认程序打开日志（`.xlsx` 交给 WPS/Excel，`.md` 交给编辑器）；**📂** 在资源管理器里定位；**↻** 立刻重读
- 打不开时（纯浏览器访问，或文件不在工作区内）自动退回复制路径，并用一行提示告诉你

## 安装

任选一种：

```bash
# 本地目录（开发时最方便，链接安装，改完刷新即生效）
# DSH → 插件 → 添加插件 → 选择本目录

# 或命令行
dsh plugin add /path/to/dsh-monitor-banner
```

装完刷新页面（Ctrl+R），状态条出现在底部。首次安装若显示「未配置日志路径」，按下一节填路径。

## 配置

`cordis.patch.yml` 里的 `config` 字段：

| 字段 | 默认 | 说明 |
|---|---|---|
| `files` | `[]` | 日志列表，每项 `{ file, label?, staleDays? }`。为空时回落到 `local.config.json` |
| `file` | `''` | 单个日志的旧写法，`files` 为空时仍然有效 |
| `label` | 文件名 | 状态条开头的名字，缺省取文件名去扩展名 |
| `staleDays` | `7` | 超过多少天算过期，到点变橙 |

## 监控多个日志

`files` 里每一项都会在状态条上占一行，各自独立算天数、独立变色、各自可点开：

```yaml
files:
  - file: 'C:\Users\me\Desktop\logs\signals.md'
    label: 'AI 需求监控'
    staleDays: 7
  - file: 'D:\notes\持仓复盘.md'
    label: '持仓复盘'
    staleDays: 14
  - file: 'D:\notes\健康记录.md'
```

超过 3 条时默认折叠，显示「还有 N 个日志，点击展开」，避免把底部越撑越高。文件暂时读不到不会影响其他行，那一行单独显示错误码。

不想把绝对路径写进配置，也可以整段放进 `local.config.json`（已在 `.gitignore` 里），字段同名：

```json
{
  "files": [
    { "file": "C:\\Users\\me\\Desktop\\logs\\signals.md", "label": "监控日志", "staleDays": 7 }
  ]
}
```

## 日志格式

文件必须是一个 Markdown 表格，数据行以日期开头，第 4 列被当作结论：

```markdown
| 日期 | 指标 | 频率 | 结论 | 证据来源 | 备注 |
| --- | --- | --- | --- | --- | --- |
| 2026-11-15 | 四大厂 capex 指引 | 每季度 | 上调 | 公司 IR 财报 | 四家 Q3 合计约 2020 亿美元 |
```

列名随意，插件只看位置：日期、指标、频率、结论。追加新行就是“更新”，不需要重启任何东西。

## 边界

- **只认 Markdown 表格**，不解析 CSV、Excel、JSON。换格式的话改 `lastRow()` 那一小段即可
- 占的是 root 级 `shell.bottom` 单槽，同一时间只能有一个插件用它
- 刷新靠 30 秒轮询，不是文件系统监听，所以写入后会有一点点延迟
- 界面文案按浏览器语言在中文/英文之间自动切换，没有接入完整的 locale 体系

## 开发

```bash
git clone <repo> dsh-monitor-banner
# 在 DSH → 插件 → 添加插件 里选这个目录，它会以符号链接安装
# 改 index.js / client.js 后刷新页面即可
```

排查时先单独确认 Host 侧是否正常，不依赖界面：

```bash
curl http://127.0.0.1:<port>/dsh-monitor-banner/status
```
